Image Recognition System

Pakistan Cricket Player Recognition System

This is an intelligent image recognition system designed to identify Pakistan cricket players from their images using Artificial Intelligence and Computer Vision.

About The Project

This uploaded cricket player's image and predicts the player's identity. The system also provides additional information such as role, age, city and recognition accuracy.

All scan results are automatically stored in the database, allowing users to view their scan history, player statistics and detection information.

Key Features

Image Recognition

Upload a cricket player's image and let the AI identify the player.

Player Information

View player role, age, city and recognition accuracy.

Scan History

Automatically save and manage previous player scans.

Statistics

Analyze detection activity, players and recognition accuracy through interactive charts.

Players Database

Browse detected Pakistan cricket players and their latest information.

Database Integration

Scan results and player information are securely stored using SQLite database technology.

How It Works

01

Upload Image

Select or drag and drop a cricket player's image.

02

AI Analysis

The trained computer vision model analyzes the uploaded image.

03

Player Detection

PakVision AI identifies the most likely player and calculates confidence.

04

Save Result

The scan result is automatically saved into the database for future reference.

Project Purpose

The purpose of this is to demonstrate how Artificial Intelligence and Computer Vision can be used to recognize and analyze cricket players through images while providing a simple and modern user experience.
